# BirdGame3

3D bird simulation game with environmental audio and reactive soundscapes, built with Unity.

## About

You explore a 3D world as a bird while the soundscape reacts to your movement and surroundings. The project focuses on environmental audio design: layered ambiences, positional sound sources and audio that responds to gameplay.

## Getting started

1. Clone the repository.
2. Open the `My project` folder in Unity Hub.
3. Open the main scene and press Play.

## Project structure

| Folder | Contents |
|---|---|
| `My project` | Unity project (scenes, scripts, assets) |
| `Documents` | Design notes and documentation |
